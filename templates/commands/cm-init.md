# Context Initialization

Please read the following files to initialize the context memory for this project:

1. **Project Overview** (if exists):
   - CLAUDE.md or README.md

2. **Core Structure**:
   - Main configuration files
   - Package manifests (package.json, pyproject.toml, etc.)
   - Important documentation

3. **Key Source Files**:
   - Main entry points
   - Core business logic files
   - Critical infrastructure

After reading these files, use `/cm-context` to verify what was captured, then `/cm-save init` to create the initial bundle.
